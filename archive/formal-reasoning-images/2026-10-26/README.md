# Formal reasoning research images

The published figures were drawn with ChatGPT’s **Create image** tool through connected Chrome. The original PNG downloads are retained without modification in `public/figures/formal-reasoning/`. WebP copies are web delivery derivatives. These are raster figures, not editable SVGs. Earlier code-generated SVG drafts were not used in the site.

No existing multi-agent figures were replaced. Their existing backups and live page remain intact. See `provenance.json` for original-file hashes.
